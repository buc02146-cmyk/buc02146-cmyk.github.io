Create a free D1 database and run this SQL in its console:\nCREATE TABLE IF NOT EXISTS recommendations (id TEXT PRIMARY KEY, category TEXT NOT NULL, title TEXT NOT NULL, url TEXT, reason TEXT NOT NULL, created_at TEXT NOT NULL, approved INTEGER NOT NULL DEFAULT 1);\nThen redeploy latest main commit under Deployments. No GitHub/Cloudflare credentials go in the browser. Public posts appear immediately after connection. To moderate a post set approved=0 by its id in D1; to remove DELETE FROM recommendations WHERE id='...';. Add Turnstile before inviting a large public audience to prevent spam.\n
