# Yourin Jeong · Personal website

A dependency-free, bilingual website for GitHub Pages. The main branch publishes the repository root.

## Updating content

- **Project list, galleries, timeline and champions:** edit `content.js`. Each bilingual string is ordered English, Korean. Project covers are mapped in `covers`. The linked portfolio boards are mapped by first PDF page and bilingual captions in `portfolioBoards`. The architecture and personal timelines have separate lists.
- **Skating, ballet and momoog:** place publication-ready media in `assets/` and add entries to the relevant list in `content.js`. Use the listed image/video format with descriptive alt text.
- **Main page copy:** edit `index.html`. Put the English paragraph inside the element and its Korean equivalent in `data-ko`.
- **Academic portfolio:** replace `portfolio.pdf` with a version cleared for publication. The current excerpt contains academic work only.
